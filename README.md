The rapid advancement of Artificial Intelligence and generative technologies has enabled the
creation of highly realistic synthetic images that are often difficult to distinguish from real
photographs. This development raises significant concerns regarding image authenticity,
misinformation, and the reliability of digital content. The proposed project, AI-Generated
Image Detection System, is designed to automatically classify an image as either Real or
AI-Generated (Fake).
The system uses the CIFAKE dataset, which contains both real and AI-generated images
belonging to two different classes. A Convolutional Neural Network (CNN) is employed to
analyze visual features and identify patterns that differentiate authentic images from AI-
generated images. The dataset is used for training, validation, and testing to evaluate the
effectiveness of the proposed model. In addition to implementing the image classification
model, the project provides a practical web-based application developed using Python and
Flask. The application allows users to upload an image through a simple interface. The
trained deep learning model processes the uploaded image and predicts whether it is Real or
Fake, along with the corresponding confidence percentage.
The proposed system demonstrates the practical use of deep learning and computer vision
techniques for digital image verification. By combining a CNN-based classification model
with a user-friendly web application, the system provides an accessible solution for detecting
AI-generated images. Further improvements can include the integration of Grad-CAM for
explainable predictions, prediction history, database support, and advanced deep learning
models to improve the accuracy and reliability of the system.

Keywords: Artificial Intelligence, AI-Generated Images, Real and Fake Image Detection,
CIFAKE Dataset, Convolutional Neural Network, Deep Learning, Image Classification,
Flask Web Application.
